ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

LAYERED DESIGN:
┌─────────────────────────────────────────────────────────┐
│ Layer 7: Main Orchestrator (main.py)                    │
├─────────────────────────────────────────────────────────┤
│ Layer 6: Reporting (reporter.py)                        │
├─────────────────────────────────────────────────────────┤
│ Layer 5: Evaluation (evaluator.py)                      │
├─────────────────────────────────────────────────────────┤
│ Layer 4: Translation (translator.py) - Sequential Load  │
├─────────────────────────────────────────────────────────┤
│ Layer 3: Model Abstraction (base.py + subclasses)       │
├─────────────────────────────────────────────────────────┤
│ Layer 2: Data Management (data_loader.py)               │
├─────────────────────────────────────────────────────────┤
│ Layer 1: Configuration & Utils (config/ + utils.py)     │
└─────────────────────────────────────────────────────────┘

DESIGN DECISIONS:
- Sequential model loading minimizes peak VRAM (fits on consumer GPUs)
- YAML-driven configuration for extensibility
- Factory pattern for clean model instantiation
- Structured logging for reproducibility
- Results caching for re-evaluation without re-translation
